# ohyeti.app

Website for **Oh Yeti!**, a pixel-art downhill runner for iPhone and Android: home page, support and privacy policy. Plain HTML/CSS served by GitHub Pages at https://ohyeti.app.

- `index.html`: home and support (the App Store support URL)
- `privacy.html`: privacy policy (the App Store / Play privacy URL)
- `app-ads.txt`: AdMob authorized sellers (added with the AdMob setup)

Art comes from the game's own sprites; fonts are Lilita One and Fredoka (SIL Open Font License, see `fonts/`).
